# esp32-feeder

Кормушка на ESP32: сервопривод открывает и закрывает заслонку по HTTP-командам из локальной сети Wi-Fi.

## Оборудование

- Плата ESP32 DEVKIT V1 (CP2102, 30 пинов)
- Сервопривод MG996R, сигнальный провод на GPIO13
- Отдельный блок питания 5 В / 2 А для сервопривода; земля общая с ESP32

## Настройка

1. Установите [PlatformIO](https://platformio.org/).
2. Скопируйте `include/secrets.h.example` в `include/secrets.h` и впишите имя сети и пароль Wi-Fi.
3. Соберите и загрузите прошивку, затем откройте монитор порта:

   ```sh
   pio run --target upload --target monitor
   ```

   В мониторе порта появится IP-адрес платы.

## HTTP API

Все команды отправляются методом `POST`.

| Запрос | Действие |
|---|---|
| `/open` | Открыть заслонку |
| `/open/{ms}` | Открыть на `ms` миллисекунд (от 300 до 300000), затем закрыть |
| `/close` | Закрыть заслонку |

Пример:

```sh
curl -X POST http://<IP>/open/1500
```

## Калибровка сервопривода

Отдельная прошивка в `src/calibrate/` помогает подобрать углы «открыто» и «закрыто». Импульс в микросекундах (500–2500) или угол (0–180) вводится в мониторе порта:

```sh
pio run -e servo-calibrate --target upload --target monitor
```

Найденные углы впишите в `SERVO_OPEN_ANGLE` и `SERVO_CLOSED_ANGLE` в `src/main.cpp`.
